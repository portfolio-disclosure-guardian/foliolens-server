# FolioLens 프로젝트 컨텍스트

## 1. 공모전

- 대회: 제10회 2026 미래에셋증권 AI Festival
- 참가 부문: 공시 Agent
- 팀 구성: 3명
  - Spring 백엔드 학습자 2명
  - 경제학과 재학생 및 증권 관심 팀원 1명
- 언어모델 제약: HyperCLOVA X 계열만 사용

## 2. 서비스 한 줄 정의

사용자의 보유 종목과 투자 이유를 기준으로 신규 공시를 분석하여,
기존 투자 가정의 변화와 포트폴리오 위험을 근거와 함께 추적하는
개인화 공시 분석 Agent

## 3. 문제 정의

일반 투자자는 많은 공시 중 무엇을 먼저 읽어야 하는지 판단하기 어렵다.

기존 서비스의 한계:

- 모든 공시를 비슷한 우선순위로 제공
- 단순 요약에 집중
- 사용자의 보유 비중을 반영하지 않음
- 사용자가 종목을 보유한 이유와 연결하지 않음
- 원공시와 정정공시의 변경점을 파악하기 어려움
- 호재·악재로 과도하게 단순화

## 4. 핵심 차별점

일반 공시 Agent가 다음처럼 답한다면:

> A사가 전환사채를 발행했습니다.

FolioLens는 다음 관점으로 답한다.

> A사는 사용자 포트폴리오의 18%를 차지합니다. 이번 전환사채는
> 기존 주주 지분 희석 가능성이 있으며, 사용자의 투자 가정인
> 안정적인 현금흐름과 관련해 추가 확인이 필요합니다.

핵심은 공시 요약이 아니라 다음 세 가지 연결이다.

```text
보유 종목·비중
+ 종목별 투자 이유
+ 신규·과거·정정공시

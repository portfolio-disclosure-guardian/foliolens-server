## 2. 생성 방식 검수

- 보고유형·보고자·수량·비율·목적·사유·거래내역은 `DIRECT_RAW`다.
- 날짜·숫자·증권종류의 승인된 일대일 표준화는 `DIRECT_NORMALIZED`다.
- 보고자 관계·변동방법·계약종류 코드는 `DERIVED_CLASSIFICATION`이다.
- 합계·비율 검증·변화량은 `DERIVED_CALCULATION`, 직전보고·정정관계는 `LINKED_RESOLVED`다.

## 3. Fact 사전

Fact ID는 의미 단위 `factKey`다. `.raw`, `.value`, `.code`는 별개의 독립 Fact를 무조건 만들라는 뜻이 아니라 같은 Fact envelope의 원문값·정규화값·분류값을 구분한 논리 경로다. 코드가 원문을 대체하지 않으며, 코드 Fact에는 코드 생성의 근거 원문을 반드시 연결한다.

### 3.5 보고·목적·증권 코드의 뜻

| 코드·용어 | 의미 | 해석 주의 |
|---|---|---|
| 일반서식 | 경영권 영향 목적 보유자 등이 사용하는 상세 보고서 | 실제 경영권 확보를 의미하지 않음 |
| 약식서식 | 일반투자·단순투자 목적 등에 사용하는 간소화 서식 | 세부정보가 생략될 수 있음 |
| `SIMPLE_INVESTMENT` | 단순투자 목적 | 단기매도 예정과 같지 않음 |
| `GENERAL_INVESTMENT` | 경영권 영향은 아니지만 적극적 주주활동 가능 | 경영권 인수 확정이 아님 |
| `INFLUENCE_CONTROL` | 경영 관련 사항에 영향력을 행사하려는 목적 | 실제 지배력 확보 여부는 별도 |
| 대표보고자 | 연명보고 집단을 대표해 제출한 자 | 집단 전체 보유량을 단독보유로 답하면 안 됨 |
| 특별관계자 | 법령상 대표보고자와 보유량을 합산하는 관계자 | 편입·제외가 반드시 매매를 뜻하지 않음 |
| 공동보유자 | 공동 취득·처분·의결권 행사 약정을 한 자 | 실제 동일 계좌 보유를 뜻하지 않음 |

| 증권 코드 | 정식 명칭·뜻 | 계산 주의 |

| `CONVERTIBLE_VOTING_SHARE` | 전환 시 의결권 주식이 되는 주식 | 전환 전 현재 의결권과 구분 |

| `COURT_DEPOSIT` | 법원 등에 주식·자산을 공탁 | 자발적 담보계약과 구분 |

## 4. 금융용어와 공식 알파벳

아래 A~I는 임의로 만든 일반 수학기호가 아니라 해당 대량보유 보고서 서식의 열 기호다. 역사적 서식 개정에 따라 열 정의가 달라질 수 있으므로 `holding.form_version`과 `holding.formula_basis_text`를 함께 저장하고, 원문 서식·주석을 확인하지 않은 채 모든 연도에 같은 식을 하드코딩하지 않는다.

| Fact ID | 의미 | 생성 방식 | 근거 |
|---|---|---|---|
| `holding.form_version` | 계산에 사용한 대량보유 보고서 서식의 버전·적용일 | `SOURCE_METADATA` 또는 `LINKED_RESOLVED` | 문서 서식 식별정보·적용 규정 |
| `holding.formula_basis_text.raw` | A~I 열과 분모·분자 정의를 설명하는 원문 주석 | `DIRECT_RAW` | 보유비율 표의 머리글·주석 |

| 기호 | 원문 열의 의미 |
|---|---|
| `A` | 의결권 있는 주권 |
| `a1` | 의결권 있는 주식으로 상환될 주식 |
| `a2` | 의결권 있는 주식으로 전환될 주식 |
| `B` | 신주인수권이 표시된 것 |
| `C` | 전환사채권(CB) |
| `D` | 신주인수권부사채권(BW) |
| `E` | 교환사채권(EB) |
| `F` | 증권예탁증권(DR) |
| `G` | 기타 주식관련 권리 |
| `H` | `a1+a2+B+C+D+E+F+G`, 보유 잠재주식 합계 |
| `I` | 의결권 있는 발행주식총수 |

- CB(Convertible Bond): 주식으로 전환할 수 있는 사채.
- BW(Bond with Warrant): 신주를 인수할 권리가 붙은 사채.
- EB(Exchangeable Bond): 발행회사가 보유한 특정 주식 등과 교환할 수 있는 사채.
- DR(Depositary Receipt): 기초주식을 바탕으로 발행한 예탁증권.

## 5. 계산

```text
주식등 보유비율 = (A + H) ÷ [I + H - (E + F + G)] × 100
주권 보유비율 = A ÷ I × 100
```

`E+F+G`는 교환대상이 기존 주식인 EB, 기초자산이 주식인 DR·파생증권, 자기주식을 교부하는 권리처럼 행사돼도 발행주식 수가 새로 늘지 않는 항목에 한하여 분모에서 제외한다. 원문 표의 기호와 주석을 보존한다.

이 식은 **원문 서식의 A~I 정의가 위 표와 일치할 때만** 사용한다. 서식 버전 또는 열 주석을 확인하지 못하면 공시 비율은 직접값으로 답하되 재계산 검증은 `UNAVAILABLE`로 둔다.

| 계산 | 공식 |
|---|---|
| 보유수 변화 | 현재−직전 |
| 지분율 변화 | 현재비율−직전비율, `%p` |
| 거래 추정금액 | 단가×수량, 조건 충족 시 참고값 |
| 담보비중 | 담보주식수÷총보유주식수×100 |

### 확장 계산과 만든 이유

| 계산 | 공식 | 대응 질문 | 의미·한계 |
|---|---|---|---|
| 보유수량 변화 | 현재 주식등 수−직전 주식등 수 | 몇 주 변했어? | 집계범위가 같을 때의 수량 변화 |
| 보유비율 변화 | 현재 비율−직전 비율 | 몇 %p 변했어? | 퍼센트포인트 변화이며 상대 변화율과 다름 |
| 상대 변화율 | 비율 변화÷직전 비율×100 | 기존 대비 몇 % 줄었어? | 질문자가 상대변화를 물을 때만 |
| 구성원 내부 비중 | 구성원 주식등 수÷보고집단 합계×100 | 집단 안에서 누가 많이 보유해? | 발행회사 전체 지분율이 아님 |
| 계약대상 비중 | 주요계약 대상수÷합산 보유수×100 | 계약된 주식 비중은? | 모든 계약을 담보로 표현 금지 |
| 담보대상 비중 | 중복 제거 담보주식÷합산 보유수×100 | 담보된 보유분은? | 반대매매 가능성·확률이 아님 |
| 자금 구성 | 자기자금 또는 차입금÷총취득자금×100 | 취득자금은 어떻게 구성돼? | 특별관계자 차입을 발행회사 부채로 처리 금지 |
| 단순 거래대금 | 절대 변동수량×실제 단가 | 거래 규모는? | 세금·수수료 포함 최종 결제금액이 아님 |
| 잠재권리 비율 차이 | 주식등 비율−주권 비율 | 잠재권리 영향은? | 실제 희석률·전환완료율이 아님 |
| 5% 임계치 후보 | 직전·현재 비율의 5% 상하 비교 | 5%를 넘거나 이탈했어? | 법 위반·보고 적법성 판단이 아님 |

수량·단가 계산은 동일 거래 행, 동일 증권종류, 실제 거래단가가 모두 확인될 때만 수행한다. 증여·상속·관계편입 등 비현금 사건에는 적용하지 않는다.

## 7. B의 구현 순서

1. 보고 요약·보유내역·변동내역·주요계약·취득자금 섹션을 구조화한다.
2. 다단 표 머리글을 복원해 A~I 열과 보유자를 정확히 연결한다.
3. 모든 원문 증권명·관계·변동방법을 보존한 뒤 표준코드를 생성한다.
4. 보고자 단독과 특별관계자 포함 집계범위를 별도 필드로 검증한다.
5. 공시 비율과 공식 재계산값을 함께 저장한다.
6. 직전보고·정정공시 관계를 확정해 기준시점 보유상태를 산출한다.
7. C가 승인한 골든 후보에서 구성원 수량과 집계합계가 동시에 1,250주 변하는지 검증한다.
8. 1,083건 배치에서 표 병합 실패·증권종류 미매핑·관계 미확정을 분리 보고한다.

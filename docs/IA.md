## 1. IA 목적

본 문서는 서비스에서 제공할 화면, 정보의 계층, 메뉴 구조, 주요 이동 경로 및 화면별 핵심 기능을 정의한다.

IA의 목표는 다음과 같다.

1. 사용자가 자신의 포트폴리오에서 중요한 공시를 빠르게 찾게 한다.
2. 공시 사실, 개인화된 영향, Agent의 해석 및 원문 근거를 혼동하지 않게 한다.
3. 최초 포트폴리오 등록부터 공시 분석과 후속 질문까지 자연스러운 흐름을 제공한다.
4. MVP와 확장 기능을 구분해 제한된 개발 기간에 핵심 화면을 완성한다.
5. 프론트엔드 화면과 백엔드 API의 연결 기준을 제공한다.

## 2. 정보구조 원칙

### 2.1 개인화 우선

- 서비스 첫 화면은 전체 공시가 아니라 `내 포트폴리오에 중요한 공시`를 보여준다.
- 공시 중요도는 보유 비중, 공시 유형, 재무적 규모 및 투자 가정 관련성을 이용한다.
- 종목을 보유하지 않은 기업의 공시는 기본 대시보드에서 노출하지 않는다.

### 2.2 사실과 해석 분리

공시 상세 정보는 다음 순서로 제공한다.

1. 원문에서 확인된 핵심 사실
2. 원공시와 비교해 변경된 내용
3. 사용자 포트폴리오와 투자 가정에 미치는 영향
4. 긍정·부정 시나리오
5. 다음 확인 지표
6. 원문 근거 및 분석 한계

### 2.3 점진적 상세화

- 대시보드: 지금 먼저 확인할 공시와 이유
- 공시 목록: 필터와 정렬을 이용한 탐색
- 공시 상세: 사실, 변화, 개인화 영향
- 원문 근거: 접수번호와 실제 공시 문서

### 2.4 행동 중심

각 화면은 사용자가 다음 행동으로 이동할 수 있어야 한다.

- 종목 추가
- 투자 이유 입력
- 중요한 공시 확인
- 정정 전후 비교
- 후속 질문
- 원문 확인

## 4. 전역 내비게이션

### 4.1 데스크톱

왼쪽 사이드바를 기본 내비게이션으로 사용한다.

```text
[서비스 로고]

대시보드
포트폴리오
공시
AI 질문
포트폴리오 위험(P1)

설정
```

상단 바에는 다음 정보를 배치한다.

- 현재 포트폴리오 이름
- 데이터 기준 시각
- 미확인 중요 공시 수
- 종목 추가 버튼
- 사용자 또는 데모 세션 메뉴

### 4.2 모바일

하단 탭은 최대 4개로 제한한다.

```text
대시보드 | 포트폴리오 | 공시 | AI 질문
```

설정과 확장 기능은 더보기 메뉴에 둔다.

### 4.3 전역 규칙

- 서비스 로고를 누르면 대시보드로 이동한다.
- 종목명은 항상 해당 보유 종목 상세 화면으로 연결한다.
- 공시 제목은 항상 공시 상세 분석 화면으로 연결한다.
- 접수번호 또는 `원문 보기`는 외부 공시 원문을 새 창에서 연다.
- 중요도 배지는 모든 화면에서 같은 색상과 명칭을 사용한다.
- 뒤로가기는 사용자의 필터와 스크롤 위치를 유지한다.

## 6. 화면별 정보 및 기능

### 6.1 ONB-001 서비스 소개

목적:

- 사용자가 서비스의 가치와 한계를 이해하고 포트폴리오 등록을 시작하게 한다.

주요 정보:

- 서비스 한 줄 설명
- `공시 요약`과 `개인화 공시 분석`의 차이
- 서비스 이용 단계
- 투자 권유 서비스가 아니라는 안내
- 데이터와 원문 근거 제공 방식

주요 행동:

- `내 포트폴리오 등록하기`
- 샘플 데모 보기(P1)

다음 화면:

- ONB-002 포트폴리오 생성

### 6.2 ONB-002 포트폴리오 생성

입력:

- 포트폴리오 이름
- 선택 설명

기본값:

- `내 포트폴리오`

주요 행동:

- 생성 후 종목 등록으로 이동

오류 상태:

- 이름 미입력
- 허용 길이 초과
- 세션 만료

### 6.3 ONB-003 종목·비중 등록

주요 정보:

- 등록된 종목 목록
- 종목별 비중
- 비중 합계
- 남은 비중

입력:

- 종목명 또는 종목코드 검색
- 보유 비중
- 선택적으로 수량, 평균 매입가, 투자 시작일

주요 행동:

- 종목 추가
- 종목 수정·삭제
- 투자 이유 입력 단계로 이동
- 투자 이유를 나중에 입력하고 완료

검증:

- 중복 종목 등록 방지
- 비중 0 초과 100 이하
- 전체 비중 100 초과 방지
- 유사 회사명이 여러 개면 종목코드가 포함된 후보 제시

### 6.4 ONB-004 투자 이유 등록

주요 정보:

- 등록 종목과 비중
- 투자 이유 예시
- 투자 이유가 분석에 사용되는 방법

입력 예시:

```text
삼성전자
- 반도체 업황 회복
- HBM 관련 매출 성장
- 안정적인 현금흐름
```

주요 행동:

- 투자 이유 추가·수정·삭제
- Agent가 구조화한 주제와 확인 지표 검토
- 등록 완료

규칙:

- 투자 이유는 선택 입력이다.
- 입력하지 않아도 일반 공시 분석을 이용할 수 있다.
- Agent가 정규화한 내용은 사용자가 수정할 수 있다.

### 6.5 DASH-001 포트폴리오 대시보드

목적:

- 사용자가 접속 후 가장 먼저 확인해야 할 공시와 이유를 한눈에 보여준다.

정보 우선순위:

#### A. 상단 요약

- 포트폴리오 이름
- 총 보유 종목 수
- 긴급 공시 수
- 주의 공시 수
- 마지막 데이터 갱신 시각

#### B. 중요 공시 피드

각 카드에 다음을 표시한다.

- 중요도 배지
- 종목명과 보유 비중
- 공시 제목 및 유형
- 접수 시각
- 한 줄 핵심 변화
- 중요한 이유 최대 3개
- 영향을 받는 투자 가정
- `분석 보기`

#### C. 투자 가정 변화

- 강화 가능
- 유지
- 약화 가능
- 확인 필요

#### D. 확인 필요 항목

- 투자 이유가 등록되지 않은 종목
- 원문 수집 실패
- 공시 분석 부분 실패
- 오래된 포트폴리오 비중

#### E. 포트폴리오 공통 위험(P1)

- 공통 위험 요인
- 관련 종목
- 합산 보유 비중
- 관련 신규 공시 수

주요 행동:

- 공시 상세 열기
- 전체 공시 보기
- 투자 이유 보완
- 종목 추가
- 질문하기

빈 상태:

- 보유 종목 없음: 온보딩으로 이동
- 관련 공시 없음: `현재 확인이 필요한 신규 공시가 없습니다` 표시
- 투자 이유 없음: 일반 분석을 제공하면서 등록을 권유

### 6.6 PORT-001 보유 종목 목록

표시 정보:

- 종목명·종목코드
- 보유 비중
- 활성 투자 가정 수
- 긴급·주의 공시 수
- 최근 중요 공시
- 마지막 분석 시각

정렬:

- 보유 비중순
- 중요 공시순
- 종목명순
- 최근 공시순

주요 행동:

- 종목 상세
- 종목 추가
- 비중 수정
- 종목 삭제

### 6.7 PORT-003 보유 종목 상세

#### 헤더

- 정식 회사명
- 종목코드
- 보유 비중
- 선택적으로 보유 수량·평균 매입가
- 정보 수정 버튼

#### 투자 가정

- 사용자가 입력한 원문
- 구조화된 주제
- 현재 상태
- 최근 영향을 준 공시
- 편집 버튼

#### 최근 중요 공시

- 중요도
- 공시 제목
- 핵심 변화
- 접수일

#### 종목 공시 타임라인

- 신규 공시
- 정정공시
- 투자 가정 상태 변경(P1)

주요 행동:

- 투자 이유 추가·수정
- 모든 공시 보기
- 종목에 대해 질문하기
- 보유 정보 수정

### 6.8 DISC-001 내 종목 공시 목록

기본 범위:

- 현재 포트폴리오의 보유 기업 공시만 표시

필터:

- 중요도: 긴급, 주의, 참고
- 종목
- 공시 유형
- 정정공시 여부
- 접수 기간
- 읽음·안읽음(P1)

정렬:

- 중요도순(기본)
- 최신순
- 보유 비중순
- 재무적 규모순

목록 정보:

- 중요도 배지와 점수
- 종목명과 보유 비중
- 공시 제목과 유형
- 정정 여부
- 접수 시각
- 한 줄 핵심 변화
- 투자 가정 관련 여부
- 분석 상태

분석 상태:

- 분석 완료
- 분석 중
- 부분 완료
- 지원하지 않는 유형
- 원문 확인 필요

### 6.9 DISC-002 공시 상세 분석

공시 상세 화면은 서비스의 핵심 화면이다.

#### A. 헤더

- 종목명·종목코드
- 공시 제목
- 공시 유형
- 접수번호·접수 시각
- 정정 여부
- 데이터 기준 시각
- 원문 보기

#### B. 중요도

- 긴급·주의·참고 등급
- 0~100 점수
- 세부 점수
- 중요한 이유
- 데이터 부족 요소

예시:

```text
중요도 78 · 긴급

- 포트폴리오 비중 18%
- 투자금액 20% 증가
- 핵심 투자 가정인 신규 사업 성장과 직접 관련
```

#### C. 핵심 사실

- 원문에서 직접 확인한 사실만 표시
- 금액, 단위, 기간, 목적, 상대방
- 사실별 근거 위치

#### D. 변경 사항

- 변경 전
- 변경 후
- 변화량·변화율
- 변경 사유
- 원공시·정정공시 근거

정정공시가 없으면 영역을 표시하지 않는다.

#### E. 투자 가정 영향

투자 가정별 다음 정보를 표시한다.

- 투자 가정 원문
- 강화 가능·유지·약화 가능·직접 관련 없음·판단 불가
- 관련 공시 사실
- 영향 경로
- 반대 해석·불확실성
- 신뢰도

#### F. 조건별 시나리오

- 긍정 시나리오와 성립 조건
- 부정 시나리오와 성립 조건
- 주가 예측이 아니라는 안내

#### G. 다음 확인 지표

- 다음 공시 또는 분기에 확인할 지표
- 확인 이유
- 현재 확보 여부

#### H. 분석 한계

- 확인할 수 없는 정보
- 데이터 누락
- 가정과 추정이 포함된 부분

#### I. 근거

- 공시 접수번호
- 공시 원문 링크
- 사용한 공시 목록
- 원문 항목 또는 문장
- 모델·규칙 버전은 상세 정보에서 확인 가능

#### J. 후속 질문

추천 질문:

- 왜 긴급으로 분류됐어?
- 정정 전후 핵심 변화만 다시 설명해줘.
- 이 공시가 내 투자 이유와 어떤 관련이 있어?
- 다음 분기에 어떤 수치를 봐야 해?

## 10. 중요도 및 상태 표현
